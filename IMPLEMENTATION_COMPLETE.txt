================================================================================

HOW TO USE
================================================================================

Generate New Puzzle:
  1. Click FILE menu at top
  2. Click "New Puzzle..."
  3. Press E (easy), M (medium), or H (hard)
  4. Puzzle appears in grid

Save Your Puzzle:
  1. Click FILE menu
  2. Click "Save Puzzle..."
  3. File saved to sudoku_puzzles/
  4. Message shows filename

Load Previous Puzzle:
  1. Click FILE menu
  2. Click "Load Puzzle..."
  3. Latest puzzle loads
  4. Continue solving!

Clear Grid:
  1. Click EDIT menu
  2. Click "Clear Grid"
  3. Grid clears, ready for new puzzle

================================================================================
KEYBOARD SHORTCUTS
================================================================================

Puzzle Generation:
  E → Easy puzzle (after FILE → New Puzzle)
  M → Medium puzzle
  H → Hard puzzle
  ESC → Cancel

Gameplay:
  1-9 → Enter number in selected cell
  0 / Backspace / Delete → Clear cell
  Arrow Keys → Navigate cells
  Tab / Shift+Tab → Move to next/previous cell

Solving:
  SPACE → Pause/resume solver
  UP/DOWN → Adjust solver speed
  ESC → Stop solver

FILE STRUCTURE
================================================================================

sudoku_puzzles/ (auto-created):
  ├─ puzzle_20260822_143045.json
  ├─ puzzle_20260822_153020.json
  └─ ...

Each file is valid JSON with:
  - puzzle: 9×9 grid (0 = empty)
  - solution: 9×9 grid (complete solution)
  - difficulty: "easy", "medium", or "hard"
  - clues: number of clues in puzzle
  - created: ISO timestamp
