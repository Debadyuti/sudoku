  KEYBOARD SHORTCUTS (FOR TESTING)
═══════════════════════════════════════════════════════════════════════════════

PUZZLE CREATION:
  FILE → New Puzzle → Easy/Medium/Hard    (click menu or use keyboard)

CELL ENTRY:
  Click cell + type 1-9                   (enter number)
  Arrow keys                              (move selection)
  Tab / Shift+Tab                         (navigate cells)

PUZZLE ACTIONS:
  F                                       (Finalize - validate grid)
  C                                       (Clear - clear all cells)

SOLVING:
  A                                       (Solve Algo - animated solving)
  S                                       (Solve Fast - instant solve)
  Space                                   (Pause/Resume during solving)
  UP/DOWN arrows                          (Adjust animation speed)
  ESC                                     (Stop solving)
  Ctrl+C                                  (Copy stats to clipboard)
